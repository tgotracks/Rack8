# Rack8

Created by **Tgo Tracks** · TRX DSP

**The bridge between producing and live looping—without a full DAW.**

Rack8 is a standalone plugin host built for loopers, with the BOSS RC-505 MKII workflow at its heart. Shape your sound with VST3 instruments and effects, build MIDI phrases, and bring them into your live looping setup from one focused workspace.

- Eight independent racks, each with eight plugin slots.
- Separate MIDI playlist tracks for separate instruments.
- Reusable patterns and a piano roll with selection, copy/paste, duplication, undo and redo.
- Live audio effects for your loop station’s output.
- MIDI clock sync and dedicated CC/program-change lanes for hardware control.
- In-app update checking and signed startup updates, once the release feed is activated.

Windows x64. Plugins and the RC-505 MKII driver are installed separately. Latency depends on your driver, buffer, routing and plugins. Back up your sessions.

The next installer is being prepared; no public release is available yet. This repository is for release downloads and the update feed only.

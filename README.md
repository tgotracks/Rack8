# Rack8

Created by **Tgo Tracks** · TRX DSP

Eight independent racks, eight plugin slots each, and a MIDI arrangement editor for Windows x64.

Download the latest installer from [Releases](https://github.com/tgotracks/Rack8/releases). Starting with v0.6.0, Rack8 includes Check for updates and automatic startup updates. Updates are signature-verified before installation.

Install once, then use the Rack8 shortcut. VST3 plugins must be installed and licensed separately. Keep copies of your sessions.
